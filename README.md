# Теневая Империя — Telegram Mini App

Стартовый проект русскоязычной сюжетной игры с реферальной системой и пополнением игрового баланса через Telegram Stars.

## Что уже есть
- Адаптивный интерфейс под iPhone и Telegram Mini Apps.
- 7 сюжетных глав (переходы по уровням).
- Задания, монеты, опыт, уровни и энергия.
- Персональные реферальные ссылки `startapp=ref_ID`.
- Серверное начисление реферальных бонусов: пригласившему 500, новому игроку 200 монет.
- Пакеты доната за 25 / 75 / 150 / 300 / 750 Stars.
- Серверная обработка `pre_checkout_query` и `successful_payment`.
- Проверка подписи Telegram `initData`; баланс хранится в SQLite на сервере.
- Локальный демо-режим интерфейса (без реальных оплат и общего аккаунта).

## Важно
Это исходный MVP, а не уже опубликованный бот. Для настоящих платежей нужен HTTPS-сервер, токен бота и установленный webhook. Не публикуй `.env` и никогда не вставляй токен в `index.html`.

## Запуск на сервере
Требуется Node.js 20+.

```bash
npm install
cp .env.example .env
# Заполни BOT_TOKEN, BOT_USERNAME, APP_URL, WEBHOOK_SECRET
npm start
```

После публикации приложения на HTTPS установи webhook (подставь домен и секрет):
```bash
curl -X POST "https://api.telegram.org/bot<TOKEN>/setWebhook" \
  -d "url=https://ТВОЙ-ДОМЕН/telegram/webhook" \
  -d "secret_token=ТВОЙ_WEBHOOK_SECRET"
```

В @BotFather:
1. Создай бота через `/newbot`.
2. Настрой Mini App / Main App и укажи HTTPS URL приложения.
3. В `.env` укажи username бота без `@`, токен и публичный URL.

Ссылка запуска игры:
`https://t.me/ИМЯ_БОТА?startapp`

Реферальная ссылка генерируется автоматически для каждого игрока:
`https://t.me/ИМЯ_БОТА?startapp=ref_ID`

## Как работают Stars
Для цифрового игрового контента используется валюта `XTR`. Сервер создаёт invoice link, отвечает на `pre_checkout_query`, а монеты начисляет только после получения `successful_payment`. Сохраняется `telegram_payment_charge_id`.
